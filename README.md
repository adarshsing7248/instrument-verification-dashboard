# Instrument Verification Dashboard

A responsive and user-friendly Instrument Verification Dashboard designed as a frontend solution for **SIH 2026 Problem Statement #26036**.

## 📊 Project Overview

This project presents a clean and responsive dashboard interface for managing and monitoring instrument verification information.

The dashboard focuses on presenting verification statistics, instrument details, verification requests, notifications, and recent activities in an organized and user-friendly interface.

## ✨ Features

- Responsive dashboard layout
- Instrument verification overview
- Total, Verified, Pending and Expired instrument cards
- Verification status charts
- Verification request charts
- Recent instruments table
- Quick actions section
- Notifications section
- Recent activity section
- Responsive sidebar navigation
- Interactive hover effects
- View All and action interactions
- Desktop, tablet and mobile layouts

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome

## 📌 Project Status

The frontend dashboard is completed using HTML and CSS.

Backend, API and database integration are planned for the next phase of development.

## 🚀 Future Scope

- Backend integration
- REST API integration
- Database connectivity
- Dynamic instrument management
- User authentication
- Real-time verification statistics
- Dynamic charts and notifications
